## SEO Requirements

### On-Page SEO (Every Page)
- Unique, keyword-optimized title tag (50-60 characters)
- Unique meta description (150-160 characters) with call-to-action
- Proper heading hierarchy (single H1, logical H2/H3 structure)
- Image alt tags (descriptive, include location where relevant)
- Internal linking between related pages
- External link to Google Business Profile
- Canonical tags

### Technical SEO

#### Site Performance:
- Optimize all images (WebP format, compressed, lazy loading)
- Minify CSS and JS
- Target 90+ on Google PageSpeed Insights
- Implement proper caching headers

#### Crawlability:
- Create XML sitemap (sitemap.xml) listing all pages
- Create robots.txt allowing full crawl
- Use semantic HTML5 elements
- Ensure all pages are within 3 clicks from homepage
- No orphan pages

#### Mobile:
- Fully responsive (test at 320px, 768px, 1024px, 1440px)
- Tap targets minimum 48px
- Readable font sizes (minimum 16px body)
- No horizontal scroll
